# 📘 Description du projet

**StudyFlow Java** représente la partie backend et intelligence artificielle de la plateforme **StudyFlow**, développée dans le cadre du projet **PIDEV – 3ème année ingénierie** à **Esprit School of Engineering** durant l’année universitaire **2025–2026**.

Cette application backend assure :
- la gestion de la logique métier,
- la communication avec la base de données,
- l’exposition des API REST,
- la sécurité du système,
- ainsi que l’intégration des modules d’intelligence artificielle.

Le projet combine les technologies Java et Python afin d’offrir une plateforme performante, intelligente et évolutive dédiée à l’e-learning et au bien-être étudiant.

---

# 🎯 Objectifs

- Développer un backend robuste et sécurisé
- Fournir des API REST performantes
- Centraliser la gestion des données et des traitements métiers
- Intégrer des fonctionnalités intelligentes basées sur l’IA
- Assurer la communication entre Java et Python
- Garantir la performance et la scalabilité du système

# 🏗️ Architecture du projet

Le projet suit une architecture modulaire basée sur une séparation claire entre :
- le backend Java,
- les services API,
- les modules IA,
- les scripts Python,
- la base de données.

## 🔹 Organisation générale

- **Spring Boot** pour la logique métier et les API REST
- **JPA / Hibernate** pour la persistance des données
- **Maven** pour la gestion des dépendances
- **Python** pour les traitements IA et Machine Learning
- Communication entre Java et Python via :
  - API REST
  - ProcessBuilder

## 🔹 Avantages de l’architecture

✅ Modularité  
✅ Scalabilité  
✅ Sécurité  
✅ Maintenance simplifiée  
✅ Intégration facile des modules IA

# 🤖 Intégration de l’intelligence artificielle

StudyFlow Java intègre plusieurs modules intelligents permettant :

- l’analyse du comportement utilisateur,
- l’analyse du stress,
